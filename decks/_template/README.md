# Папка одной презентации

Одна папка = одна презентация. Создаётся командой `/deck-start <название>`, которая копирует сюда `_template/` и формирует `00-brief.md` по итогам разговора.

## Что должно быть в папке после прохождения всех этапов

- `00-brief.md` — заполнен после `/deck-start`.
- `reference.pptx` — PPTX-эталон, задающий стиль (опционально, копируется командой `/deck-start`).
- `reference-notes.md` — разбор референса (опционально, парный с reference.pptx).
- `01-storyline.md` — заполнен после `/storyline`.
- `02-content.md` — заполнен после `/content`.
- `03-deck.pptx` — финальный файл, создан `/build-deck`.

## Если зашёл в эту папку руками

Посмотри, какие файлы есть, и зови соответствующую команду:
- Только `00-brief.md` → `/storyline`.
- Есть `01-storyline.md` → `/content`.
- Есть `02-content.md` → `/build-deck`.

Или просто запусти `/deck-resume <имя-папки>` — она сама определит, на каком этапе ты остановился.
