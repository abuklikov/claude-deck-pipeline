# Библиотека PPTX-эталонов

Многоразовые референсы стиля. Рядом с каждым `<name>.pptx` кладётся `<name>.md` с описанием в 1–2 предложения: для кого презентация, какой характер (клиентский питч, внутренний апдейт, техдок…).

При `/deck-start` агент показывает этот список, и выбранный эталон копируется в папку новой презентации как `reference.pptx`.

> Сами `.pptx` в репозиторий не коммитятся (см. `.gitignore`) — они часто содержат рабочие материалы.
