# Общие правила сборки

Сюда кладётся `build-rules.md` — инвариантные технические правила работы с `python-pptx`, не зависящие от стиля конкретной презентации: как искать плейсхолдеры в layout, как переносить текст в shape, как обрабатывать таблицы и списки.

Стиль конкретной презентации здесь **не** живёт — он задаётся per-deck через `reference.pptx`.
